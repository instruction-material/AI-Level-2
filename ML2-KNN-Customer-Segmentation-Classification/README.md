# Customer segment imitation with KNN

Use the supplied `customers.csv`: 200 observations with annual income and spending score as inputs. IDs, age and gender are excluded from the learned features. Source: [Customer Segmentation Tutorial in Python](https://www.kaggle.com/vjchoudhary7/customer-segmentation-tutorial-in-python). This is a supplied teaching table, with no measured customer-type target.

Run with Python 3.14 in an isolated environment:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
.venv/bin/python main.py --output-dir output
```

The program locates its CSV beside `main.py`, so it can run from another working directory. It writes `classification-report.json`, `before_clustering.png` and `clustered_graph.png` to the chosen output directory. The checked-in plots are previews generated by this exact program.

## Follow the data boundary

Reserve 50 of the 200 raw rows with seed 42 before fitting anything. Fit `StandardScaler` plus a seeded, bounded five-cluster `KMeans` pipeline on the 150 training rows. Its predictions supply the training and held-out proxy labels. Because labels do not exist when this initial split is made, it is unstratified; inspect the reported class supports and confusion matrix. This variant keeps every learned clustering parameter out of the held-out rows. When importing already frozen labels from prior work instead, stratify when every class has enough observations.

Fit a separate `StandardScaler` plus three-neighbor `KNeighborsClassifier` pipeline on the training rows and proxy labels. Fix the model before inspecting test results. Compare its held-out accuracy, macro F1 and confusion matrix with a most-frequent `DummyClassifier` fitted only on training labels. Matrix rows are actual proxy labels; columns are predictions, in `class_labels` order. Label numbers identify arbitrary clusters, not an ordered scale.

For the hypothetical point `[90, 20]`, inspect its prediction and location on the cluster plot. The manual neighbor trace counts observations by row, preserving identical feature vectors. Manual voting resolves equal counts by first encountered neighbor; scikit-learn's uniform vote uses sorted class order. This distinction matters when constructing a tied example.

## Hand checks and interpretation

Training values 0, 2 have mean 1 and population variance 1, so their scaled values are -1, 1. Transforming held-out 100 yields 99; including it while fitting the mean would change every distance. For training points 0, 0, 3 with labels A, A, B and query 0, all three observations remain neighbors and A receives two votes.

Actual labels A,A,B and predictions A,B,B give `[[1,1],[0,1]]`: accuracy 2/3 and macro F1 2/3. Compare these calculations with the saved report before interpreting the larger table.

The classifier learns to imitate a particular training clustering rule. Its scores measure agreement with that generated rule, not independent evidence of real customer types or behavior. The query is hypothetical; this demonstration supplies no basis for targeting people. Changing the cluster seed can change the labels and the task itself. The saved split IDs, scaling statistics, centers, predictions and versions make this specific run reproducible.
