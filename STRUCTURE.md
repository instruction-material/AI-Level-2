# AI-Level-2 Structure

This repository backs `Machine Learning`. It contains a mix of legacy ML project
folders and generated supplemental wrappers.

Active public folders stay at the repository top level and must be linked by the
live catalog. Folders not linked by the live catalog on 2026-05-14 were moved to
`_archived-unlinked/`.

New supplemental projects should use complete deterministic slugs and the
`README.md`, `starter/`, and `solution/` wrapper shape.
