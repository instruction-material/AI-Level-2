# Source case support and verification

These explicit reference engines and the deterministic weather-pattern generator are the source templates copied into the independently runnable role projects. Every assigned role includes its own model and inputs; it does not import this support folder. JSON case indexes identify each named implementation task.

Run python3 -I -B ML-Source-Cases/run_tests.py from the repository root to execute all 208 independent contracts, including the earlier 145 checks. The new 63 cover hand-worked clustering/metric results, actual entry points, grouped fit boundaries, test-label mutation, polynomial solving, all 260 CNN derivatives, bounded PNG decoding, training-only augmentation, CPU limits and the 36-file image project bound.

Reproduce the 32 original weather-pattern images with python3 -B ML-Source-Cases/generate_weather.py destination. It writes exact PNG bytes and grouped metadata.csv. The four classes share procedural drawing rules; the images teach a bounded workflow and do not establish real-photo recognition.

The original source course files and archived historical notebooks remain available for separate review. A passing source suite does not certify complete teaching, site/browser import, publication or live activation.
