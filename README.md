# AI Level 2 Machine Learning

Canonical source layout in this repo is folder-first: each project should live in
its own directory with any local assets beside it.

Generated Replit/Poetry files have been removed. Keep starter and solution
material in the project directory that owns it; do not re-add generated package
metadata or root-level standalone copies.

## Complete supplied source workflows

The thirty supplemental pairs contain specific algorithm exercises and worked
references. Five independent offline core workspaces cover environment/data
inspection, evaluation planning, housing regression, a four-class image CNN
and a classification capstone. All are standard-library Python projects with
their required local inputs.

Run python3 -I -B ML-Source-Cases/run_tests.py for all 208 independent source
contracts. See COURSE_SOURCE_MANIFEST.md for inventory and SOURCE_BACKLOG.md
for exact scope and the remaining site/whole-course review boundary.

Each starter names a function to implement; its solution is a complete worked
reference. Record the Python version, input checksum, split/group plan,
preprocessing boundary and model-choice rule before interpreting a result.
